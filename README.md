# SE-Git-hw
PROJECT SUMMARY
This project demonstrates core Git workflows including repository setup, branching, committing changes, creating pull requests, and resolving merge conflicts. The goal is to simulate real‑world version control scenarios that occur during collaborative software development. 
MERGE CONFLICT EXPLANATION
A merge conflict occurred because two branches modified the same line in the same file (hello.py) in different ways. Git could not automatically decide which version to keep. To resolve the conflict, I opened the conflict editor in GitHub, reviewed both versions, removed the conflict markers and chose a final version of the code. After cleaning the file, I marked the conflict as resolved and completed the merge.
